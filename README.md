# Antigravity 简体中文补丁

面向 Google Antigravity 独立桌面端的社区汉化工程，与官方无隶属关系。首个目标版本为 Windows 2.24.0。

## 当前状态

工程初始化；尚未开发或安装补丁，尚未完成界面验证。

## 原则

- 仅翻译界面控件，排除对话、代码、终端、用户输入与文件路径。
- 安装前核对版本与指纹，原始备份仅在本机保存。
- 不关闭归档安全校验，不修改可执行文件。
- 应用更新后重新适配。

## 版本管理

main 保存已验证阶段成果，dev 用于开发。每项独立改动完成后提交、推送并核对远程提交。通过验收后才创建 v0.1.0 标签。

工程回退使用 git revert 保留历史；应用恢复使用本地原始备份，两者互不替代。
