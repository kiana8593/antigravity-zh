# 词条与验证

词典为 `dictionary/zh-CN.json`：`rules` 绑定固定控件，`settingsNav` 绑定设置导航，`settings` 绑定设置内容区。匹配完整原文，保留前后空白；未知文本保持英文。

## 来源与适配

- 通过本机 2.24.0 的静态界面资源确认 data-testid 与菜单原文；资源文件仅在忽略目录 work 中保留，未上传。
- 原版截图确认固定导航、顶部菜单、概览以及常规设置的原文。
- 设置根节点通过设置打开参数、账号导航锚点与固定内容列共同识别；找不到边界时不翻译设置内容。
- 动态 UI 使用 MutationObserver，60 毫秒合并变化；翻译期间暂停观察自身写入，避免循环。
- 聊天、编辑器、终端及可编辑区域被排除；流式聊天更新不会触发全局扫描。

## 状态定义

- 已编写：原文与选择器已登记。
- 自动验证：隔离 DOM 或归档测试通过。
- 现场确认：在实际应用看到中文、布局正确并确认点击仍正常。

dev.2 已现场确认主要导航、内置侧栏标题、常规/应用设置的部分标签说明、自动化列表/空状态/新建表单、主输入占位提示和中文原生退出确认。尚未逐项验收全部词条；未验证覆盖率不以百分比报告。

## 首版保留英文

自定义分组标题、项目与对话名称；模型与产品名称；输入框正文及未登记的占位提示；低频或动态错误；尚未登记的设置描述；操作系统对话框；第三方网页。新增支持必须先建立可靠边界，不采用全页面无差别词典替换。

## dev.2 扩展

- 设置根节点优先使用固定弹层容器，设置导航只覆盖内置导航分组，排除同名项目。
- 输入框仅处理指定控件的占位属性；Lexical 主输入框只处理与编辑正文并列的独立提示节点。
- 控件内部嵌套的工具提示通过关联标识定位，避免通用翻译任意 tooltip。
- 原生退出确认只替换四项经过匹配计数及语法校验的固定代码片段，按钮索引和行为不变。
- 当前共登记 287 条独立界面原文（含重复场景去重）以及 4 项原生窗口文案；相较 dev.1 新增 180 条界面原文。
