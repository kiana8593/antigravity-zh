# 词条与翻译范围

## v0.1.0

词典为 `dictionary/zh-CN.json`，共登记 **287 条独立界面原文**及 **4 项原生退出确认文案**。相同原文在不同控件中可以重复绑定，不以总键数表示实际覆盖率。

- `rules`：固定导航、侧栏内置标题、菜单、概览、自定义和自动化页面控件、搜索占位属性。
- `settingsNav`：设置中的内置导航与固定分组标题。
- `settings`：固定设置内容区中的标签、说明及分段文字。
- `inputPlaceholder`：与 Lexical 可编辑正文并列的独立占位提示。
- `native`：原生退出确认的四项固定字符串，定位数量不符合预期即停止构建。

## 边界

- 使用完整原文匹配，保留节点身份，不重写整个 HTML 内容。
- 设置导航只处理内置分组，排除同名项目与账号名称。
- 搜索及提示词输入框仅替换占位属性；主输入框仅处理独立提示节点，实际输入不变。
- 工具提示根据固定控件的关联标识定位，不对所有 tooltip 通用替换。
- 聊天、代码、终端、可编辑正文、项目/文件/对话名和模型名不做通用翻译。
- 合并动态更新，并在翻译自身节点时暂停观察，防止循环；流式聊天更新不会触发全局扫描。

## 已知未覆盖

部分模型/项目选择器状态、低频或动态错误、尚未登记的设置描述、第三方插件说明、外部网页和操作系统对话框保持原文。未验证的覆盖率不以百分比报告。

主要界面现场检查和自动化测试结果见 [验证记录](VALIDATION.md)。新增覆盖应先确认控件边界，再增加词条和回归测试。
