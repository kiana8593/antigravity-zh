# v0.1.0：首个公开版本

面向 **Antigravity Windows 独立桌面端 2.24.0** 的简体中文补丁。

## 内容

- 287 条独立界面原文及 4 项原生退出窗口文案。
- 常用导航、侧栏、菜单、部分设置、自定义/自动化页面与表单、搜索和主输入占位提示。
- 自动构建、版本与文件指纹检查、原始备份、状态查询和恢复。
- 22 项自动化测试通过；已完成主要界面检查和真实原版恢复校验。
- MIT 开源许可，公开提交使用 GitHub 隐私邮箱。

## 安装

1. 安装受支持的 Node.js，推荐 Node.js 24 LTS。
2. 下载 `antigravity-zh-v0.1.0-windows.zip` 并完整解压。
3. 等待任务结束，完全退出 Antigravity。
4. 先运行 `检查状态.cmd`，检查通过后运行 `安装汉化.cmd`，再正常启动应用。

恢复时退出应用并运行同一工程内的 `恢复原版.cmd`。请保留整个 `backups` 目录；备份不会上传到 GitHub，也不包含在发布包中。

## 兼容性与限制

- 仅适配登记指纹的 2.24.0 独立桌面端，不适用于 IDE 或其他版本直接套用。
- 这是首个功能版本，仍有部分低频提示、选择器状态及第三方说明保持英文。
- 多窗口、全部低频弹窗及所有窗口尺寸尚未完整验收。
- 应用升级后需重新适配，工具不关闭自动更新或安全校验。
- 发布包不包含 Antigravity 本体、预打补丁的原应用归档、个人数据或日志。

ZIP 的 SHA256 校验值见同名 `.zip.sha256` 附件。完整使用说明见仓库 README。
