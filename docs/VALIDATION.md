# 验证记录

## v0.1.0 — 2026-10-19

适配目标为 Google Antigravity Windows 独立桌面端 2.24.0。兼容性文件中的 SHA256 来自原始应用归档和可执行文件，不包含用户数据。

### 自动化验证

22 项测试覆盖：

- ASAR 编解码、Unicode、完整性分块校验、损坏数据及未知校验开关。
- 首次安装、重复安装、确定性重建、恢复后字节一致、运行中拒绝、未知修改、备份损坏或缺失、并发与写入冲突。
- 固定控件、嵌套标题、动态节点、工具提示及观察循环。
- 聊天、代码、终端、用户输入、同名项目与模型排除。
- 搜索框与主输入独立占位提示，保证实际输入不变。
- 原生窗口定位不匹配时停止构建。

安装失败场景均在隔离的模拟安装目录中验证，不对运行中的真实任务尝试安装。

- 原生退出确认的标题、正文、说明和按钮均显示中文，正常退出成功。

- 从 Git 检查点独立重建，产物与对应安装版本一致。
