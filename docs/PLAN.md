# 维护计划

## v0.1.0

- 支持 Windows Antigravity 2.24.0 的常用导航、设置、菜单、自动化表单及提示。
- 使用固定界面范围和完整原文匹配，排除聊天、代码、终端与用户内容。
- 安装前核对版本、归档与可执行文件指纹，保留可校验的原始备份。
- 提供安装、构建、状态和恢复入口，发布源码与 Windows 工具包。

## 后续迭代

- 逐项补齐未登记的低频界面并记录现场验证状态。
- 完善多窗口和不同窗口尺寸检查。
- 按应用更新版本建立独立的兼容性指纹，避免套用旧版补丁。

## 发布约定

`main` 保存已发布源码，`dev` 用于开发，版本标签固定每次发布。新增词条或修改安装逻辑后运行测试与隐私检查。

只上传自行编写的补丁工具、词典和文档。应用归档、解包资源、备份、日志、截图和账号凭据保持本地保存。
