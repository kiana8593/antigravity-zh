# 实施计划

1. 初始化工程与私有 GitHub 仓库，推送初始提交。
2. 检查实际界面，整理带定位范围的词条并开发预加载翻译原型。
3. 开发版本及指纹检查、归档构建、备份、安装、状态和恢复工具。
4. 验证常用界面、动态弹窗、多窗口与排除内容；演练失败与恢复。
5. 通过验收后合并 main、打 v0.1.0 标签并推送。

## 首版目标

常用导航、设置、菜单、按钮和状态提示；低频错误、外部网页和系统对话框暂不承诺。

## 安装事务

检测应用退出 → 核对兼容指纹 → 构建并校验归档 → 保存不可覆盖原始备份 → 替换 → 验证。遇未知版本、未知修改、运行中或备份异常均停止。

## 验收

- 启动、切页、弹窗、多窗口与重开正常。
- 聊天、代码、终端、文件名、路径和用户输入不变。
- 中文无明显截断；动态翻译无循环或明显卡顿。
- 首次/重复安装、版本不符、运行中、写入失败和恢复有明确结果。
- 恢复后 SHA256 与原始备份一致。
- 远程仓库私有，本地远程提交一致，可从历史提交重建。

## 数据边界

仓库仅收录自行编写的源码、词典、文档与指纹。应用归档、解包资源、原始备份、日志、截图、账号配置和凭据一律不提交。
